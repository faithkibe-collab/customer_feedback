# Customer Feedback Analysis

Lab: Parametric vs. Non-Parametric — Analyzing Customer Feedback

Analyzes whether a restaurant chain's menu redesign significantly changed:
1. Customer satisfaction ratings (before vs. after)
2. Customer return visit rates (new menu locations vs. control)

Uses paired t-test / Wilcoxon signed-rank test for ratings, and a chi-square
test of independence for return visits, with Cohen's d and Cramer's V effect
sizes reported for each.

See `parametric_lab_starter.ipynb` for the full analysis.
